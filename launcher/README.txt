FormatDrop 1.0.0
================

1. FormatDrop-1.0.0.exe를 더블클릭합니다.
2. 잠시 후 기본 브라우저에서 FormatDrop이 자동으로 열립니다.
3. FormatDrop 제어 창을 닫으면 로컬 서버와 앱이 함께 종료됩니다.

특징
----
- 별도의 설치나 Python 실행이 필요하지 않습니다.
- 모든 이미지와 PDF 처리는 사용자 컴퓨터 안에서 이루어집니다.
- Windows 방화벽에서 확인 창이 표시될 경우, 로컬 통신만 사용하는 앱입니다.

문제 해결
---------
- 브라우저가 열리지 않으면 제어 창의 "브라우저에서 열기" 버튼을 누르세요.
- 페이지가 보이지 않으면 앱을 종료한 뒤 다시 실행하세요.
- 백신 또는 SmartScreen이 처음 실행을 확인할 수 있습니다. 파일의 SHA256은 함께 제공된 SHA256SUMS.txt에서 확인할 수 있습니다.
